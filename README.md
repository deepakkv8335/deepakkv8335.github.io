# Deepak K V Portfolio

A React-based developer portfolio showcasing software projects, technical skills, internship experience, and real-world applications through a premium, responsive interface with reusable components, smooth animations, and scalable architecture.

**Live Website:** https://deepakkv.co.in

## Overview

This portfolio highlights my journey as a Software Developer through real-world projects, full-stack development experience, and modern web technologies. It is built with a scalable React architecture and designed to provide a fast, responsive, and polished user experience across devices.

## Features

* Responsive, mobile-first design
* Dynamic project showcase with dedicated project pages
* Smooth animations with Framer Motion
* Dark-themed modern interface
* Contact form powered by EmailJS
* SEO optimization with Open Graph, JSON-LD, sitemap, and robots.txt
* Automatic deployment through GitHub Actions

## Tech Stack

* React
* Vite
* Tailwind CSS
* Framer Motion
* React Router
* EmailJS

## Getting Started

### Prerequisites

* Node.js 20.19 or later

### Installation

```bash
git clone https://github.com/deepakkv8335/deepakkv8335.github.io.git
cd deepakkv8335.github.io
npm install
```

### Run Locally

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

## Available Scripts

| Command                | Description                             |
| ---------------------- | --------------------------------------- |
| `npm run dev`          | Start the development server            |
| `npm run build`        | Create a production build               |
| `npm run preview`      | Preview the production build locally    |
| `npm run lint`         | Run ESLint                              |
| `npm run lint:fix`     | Fix linting issues automatically        |
| `npm run format`       | Format the codebase with Prettier       |
| `npm run format:check` | Check formatting without making changes |
